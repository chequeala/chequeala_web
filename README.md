# chequea.la Web

Bienvenido al repositorio de **chequea.la**, la web de la línea de ayuda diseñada para ayudar a los propietarios de sitios web a implementar buenas prácticas de seguridad y protección digital. Este proyecto está desarrollado con **Vue 3**, **Vite** y **vue-i18n** para soporte multilingüe.

## URL del Proyecto

Puedes acceder al proyecto en: [https://chequea.la](https://chequea.la)

## Descripción del Proyecto

Chequea.la proporciona un **checklist interactivo** que permite a los propietarios de sitios web verificar y mejorar la seguridad de sus sitios. La herramienta está diseñada para ser fácil de usar y ofrecer recomendaciones específicas para sitios web generales y sitios hechos en WordPress.

## Herramientas

- **Vue 3**: Un framework de JavaScript para construir interfaces de usuario.
- **Vite**: Un generador de proyectos y servidor de desarrollo ultrarrápido.
- **vue-i18n**: Una biblioteca para la gestión de traducciones y soporte multilingüe en aplicaciones Vue.
- **Bootstrap 5.3.0**: Un marco de CSS para diseñar y desarrollar sitios web responsivos y móviles.

## Checklist

La herramienta incluye una lista de tareas de seguridad que cubren aspectos esenciales como:

- Configuración de HTTPS
- Protección contra ataques XSS
- Mejores prácticas de autenticación y autorización

Además, ofrece recomendaciones específicas para sitios hechos en WordPress, incluyendo:

- Configuración segura de plugins
- Mejora de la seguridad del panel de administración

## Configuración del Proyecto

Para comenzar con el desarrollo, sigue estos pasos:

### Configuración del IDE Recomendada

- [VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (desactivar Vetur).

### Configuración del Proyecto

````sh
npm install

### Compile and Hot-Reload for Development

```sh
npm run dev
````

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
